# Scenario
The solution must support SMB protocol for Windows-based applications and NFS protocol for Linux-based applications. Additionally, the storage must deliver sub-millisecond latencies for optimal performance. Instances across all Availability Zones must be able to read and write data to the storage seamlessly.

# Question
Select TWO.

# Options
1. Deploy FSx for Lustre to provide a shared file system for high-performance workloads with NFS support.
2. Set up an FSx for NetApp ONTAP Multi-AZ file system to provide SMB and NFS support with sub-millisecond latencies.
3. Modify the user data in each application's launch template to attach the FSx for NetApp ONTAP file system.

# Explanation
1. While FSx for Lustre supports NFS and is optimized for high-performance workloads, it does not support SMB. Additionally, Lustre is primarily intended for data processing and analytics workloads, not general-purpose shared storage.
