# Scenario
Systems Manager to perform maintenance tasks during maintenance windows. EC2 instances that require a restart after notifications from AWS Health. automated solution to remediate these notifications.

# Question
configure the EventBridge rule?

# Options
1. Configure an event source of AWS Health, a service of EC2. and an event type that indicates instance maintenance. Target a Systems Manager document to restart the EC2 instance.
2. Configure an event source of AWS Health, a service of EC2, and an event type that indicates instance maintenance. Target a newly created Lambda function that registers an automation task to restart the EC2 instance during a maintenance window.
3. Configure an event source of EC2 and an event type that indicates instance maintenance. Target a newly created Lambda function that registers an automation task to restart the EC2 instance during a maintenance window.

# Explanation
The Lambda function performs the custom logic: it registers an Automation task with a Systems Manager Maintenance Window, so the restart happens only when the Maintenance Window executes.

1. This would execute the document immediately when the Health event occurs.
3. The trigger is wrong. The event originates from AWS Health, not from Systems Manager Maintenance Windows.
