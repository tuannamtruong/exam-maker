# Scenario
A company is building a serverless SFTP endpoint and expects workloads that need high file-system IOPS and POSIX semantics.

# Question
Which storage backend should be used?

# Options
1. S3 + AWS Transfer Family SFTP
2. EFS + AWS Transfer Family SFTP
3. EBS + self-hosted SFTP on EC2

# Explanation
AWS Transfer Family supports S3 or EFS as backends. EFS is serverless elastic file storage with POSIX semantics; EFS General Purpose with Elastic throughput gives high IOPS and throughput — best for high file-system IOPS workloads. S3 works but is object storage, not natural for POSIX file operations. EBS is not a Transfer Family backend at all — it would require running SFTP on EC2, which is no longer serverless.
