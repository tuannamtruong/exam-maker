# Scenario
A serverless learning portal uses:

Lambda
API Gateway

An SQL injection attack caused data loss. The solution must:

Prevent future SQL injection attacks.
Track historical changes to WAF rules and configurations.
Be the most cost-effective solution.

# Options
1. Add a web access control list in front of the Lambda functions using WAF to block requests that contain malicious SQL code. Track the changes to your web access control lists (web ACLs) such as the creation and deletion of rules including the updates to the WAF rule configurations using Firewall Manager.
2. Add a web access control list in front of the API Gateway using WAF to block requests that contain malicious SQL code. Implement a scope-down statement in the WAF rule to limit inspection to specific request components and improve performance. Track the changes to web access control lists (web ACLs), such as the creation and deletion of rules, including updates to WAF rule configurations, using Config.
3. Launch a new ALB and set up WAF to block requests that contain malicious SQL code. Place the API Gateway behind the ALB and use the Firewall Manager to track changes to your web access control lists (web ACLs) such as the creation and deletion of rules including the updates to the WAF rule configurations.

# Explanation
Scope-down statement
Instead of inspecting every request: "Inspect all requests"
you can restrict inspection to only relevant requests:


Only inspect:
POST /login
POST /signin

instead of:
GET /images/*
GET /css/*
GET /favicon.ico

1. You have to use WAF in front of the API Gateway and not directly to the Lambda functions. Firewall Manager is primarily used to manage your Firewall across multiple AWS accounts under your Organizations and hence, it is not suitable for tracking changes to WAF web access control lists. You should use Config instead.
3. Launching a new ALB entails additional cost and is not cost-effective. In addition, Firewall Manager is primarily used to manage your Firewall across multiple AWS accounts under your Organizations. Using Config is much more suitable for tracking changes to WAF web access control lists.
