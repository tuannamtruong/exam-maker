# Scenario
notification whenever a KMS key exceeds 90 days without rotation.

# Options
1.	Configure KMS to publish to an SNS topic when keys are more than 90 days old. 
2.	Configure EventBridge to invoke a Lambda function that calls the Trusted Advisor API and publishes to SNS. 
3.	Develop an AWS Config custom rule that publishes to an SNS topic when keys are more than 90 days old. 
4.	Configure Security Hub to publish to an SNS topic when keys are more than 90 days old.

# Explanation
you create a custom Config rule (typically backed by a Lambda function) that solves this problem.
