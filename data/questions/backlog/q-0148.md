# Scenario
A company stores legal documents in an Amazon S3 bucket. These documents come from the AWS Management Console and several applications for which the company lacks access to the source code. The company's legal team interacts with these documents through a web application. The legal team can mark individual documents for legal hold by setting a LegalHold tag to true.
A DevOps engineer must create an automated process to delete all objects that are more than 90 days old and that have not been marked for legal hold.

# Question
TWO

# Options
1. Create an S3 Lifecycle policy for the S3 bucket that deletes objects that are older than 90 days.
2. Set an S3 event notification to initiate an AWS Lambda function upon object creation. Configure the Lambda function to add the LegalHold tag with a value of false if the tag is not present in the request.
3. Create an S3 bucket policy that uses the StringEquals: { "s3:ExistingObjectTag/LegalHold": "true" } condition to  for all objects that have been marked for legal hold. deny s3:DeleteObject
4. Create an S3 Lifecycle policy that includes a filter rule for the LegalHold tag with a value equal to false. Configure the S3 Lifecycle policy to delete objects that are older than 90 days.

# Explanation
1)	S3 Lifecycle policies use rules that determine when to change S3 storage classes or delete expiring objects based on object age. This solution offers no specification to keep objects that have the LegalHold tag set to true. Therefore, this solution would delete documents that have been marked for legal hold.
2)	When an object is uploaded to Amazon S3, an S3 event notification can initiate an AWS Lambda function that checks for the presence of the LegalHold tag. If the tag does not exist, the Lambda function adds the tag and sets the value to false. When the tag is set to false upon object creation in this manner, you can write a filter rule to specify which objects to delete or keep.
3)	This solution would not meet the requirements because the DeleteObject action does not support the ExistingObjectTag condition key as stated.
4)  This solution results in the deletion of all objects that are not marked for legal hold and that are more than 90 days old.
