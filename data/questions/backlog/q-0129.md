# Scenario
automatically detect any IAM access key owned by the firm that is accidentally or deliberately exposed on a public GitHub repository

# Options
1. EventBridge rule with an aws.health event source and the AWS_RISK_CREDENTIALS_EXPOSED event to monitor any exposed IAM keys from the Internet
2. AWS Health rule for the AWS_RISK_CREDENTIALS_EXPOSED event to monitor any exposed IAM keys from the Internet
