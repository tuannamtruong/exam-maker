# Scenario
database scripts via S3 in an unauthenticated manner.

# Question
MOST secure way to fix this?

# Options
1. Secure the S3 bucket by removing unauthenticated access through a bucket policy. Add an IAM access key and a secret access key in the CodeBuild as an environment variable to grant access to S3. Download the database scripts using the CLI.
2. Deny unauthenticated access from the S3 bucket through an IAM Policy. Add an IAM access key and a secret access key in the CodeBuild as an environment variable to grant access to S3. Utilize the CLI to fetch the database scripts.
3. Secure the S3 bucket by removing unauthenticated access through a bucket policy. Update the service role of the CodeBuild project to grant access to S3. Download the database scripts using the CLI.

# Explanation
You need a CodeBuild service role so that CodeBuild can interact with dependent AWS services on your behalf. In this scenario, the S3 bucket will be safeguarded from unauthorized access by utilizing a bucket policy.

1. While the use of IAM access key and secret access key can provide S3 access to CodeBuild, it is not the most secure approach to address the issue.
2. An IAM policy alone cannot secure an S3 bucket from unauthorized access. A bucket policy must be used instead. Furthermore, this option uses IAM access key and secret access key, which is not the most secure way.
