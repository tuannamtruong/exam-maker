# Scenario
The household information uploaded on the portal contains personally identifiable information (PII) and is stored in encrypted files on an S3 bucket. Data security is a top priority, and S3 access logs along with CloudTrail have been enabled to track access to S3 objects. To further enhance security, there is a need to verify that data access meets compliance standards and to receive alerts in case of any risk of unauthorized access or inadvertent data leaks.

# Question
Which of the following AWS services enables this?

# Options
1. Use Security Hub to aggregate security findings from multiple AWS services.
2. Use GuardDuty to monitor malicious activity on your S3 data.
3. Use Inspector to alert you whenever a security violation is detected on your S3 data.
4. Use Macie to monitor and detect usage patterns on your S3 data.

# Explanation
1. Security Hub simply aggregates security findings from services like Macie and GuardDuty but does not directly monitor or classify sensitive data in S3. While useful for a centralized security overview, it does not proactively identify PII exposure risks.

2. Although GuardDuty can continuously monitor malicious activity and unauthorized behavior in your S3 bucket, it still is not capable of recognizing sensitive data such as personally identifiable information (PII), which is required in the scenario.

3. Inspector is typically an automated security assessment service that helps improve the security and compliance of applications deployed on AWS.
