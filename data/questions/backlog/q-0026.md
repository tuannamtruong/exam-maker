# Scenario
A distributed microservice-based serverless app has data retrieved and written from multiple DynamoDB tables. The architect must ensure efficient retrieval and writing of data without impacting baseline performance, while ensuring seamless access to patient information for healthcare professionals.

# Question
What is the MOST operationally efficient solution?

# Options
1. Launch AWS Lambda functions with an edge-optimized API Gateway.
2. Utilize AWS AppSync pipeline resolvers.
3. Set up DynamoDB connector for Athena Federated Query.
4. Use CloudFront functions.

# Explanation
AppSync pipeline resolvers offer an elegant server-side solution to address the common challenge faced in web applications—aggregating data from multiple database tables. Instead of invoking multiple API calls across different data sources, which can degrade application performance and user experience, AppSync pipeline resolvers enable easy retrieval of data from multiple sources with just a single call. By leveraging Pipeline functions, these resolvers streamline the process of consolidating and presenting data to end-users.

1. Launched AWS Lambda functions with an edge-optimized API Gateway is more on improving the connection time for the end-users instead of providing access to multiple DynamoDB tables as data sources.
3. Although Athena can allow the application to access multiple DynamoDB tables, it does not support write operations. Result can only be stored in S3.
