# Scenario
A telecommunications company is planning to grant AWS Console access to its developers. Company policy requires the use of identity federation and role-based access control. Currently, the roles are already assigned via groups in the corporate Microsoft Active Directory.

# Question
What combination of the following services can provide developers access to the AWS console? (Select TWO.)

# Options
1. AWS Directory Service Simple AD
2. AWS Directory Service AD Connector
3. IAM Groups
4. IAM Roles

# Explanation
1. this only provides a subset of the features offered by AWS Managed Microsoft AD, including the ability to manage user accounts and group memberships, create and apply group policies, securely connect to EC2 instances, and provide Kerberos-based SSO. In this scenario, the more suitable component to use is the AD Connector since it is a directory gateway with which you can redirect directory requests to your on-premises Microsoft Active Directory.
3. this is just a collection of IAM users. Groups let you specify permissions for multiple users, which can make it easier to manage the permissions for those users. In this scenario, the more suitable one to use is IAM Roles in order for permissions to create AWS Directory Service resources.
