# Scenario
A company must integrate the Lightweight Directory Access Protocol (LDAP) directory service from the on-premises data center to the AWS VPC using IAM. The identity store currently being used is not compatible with SAML.

# Question
Which of the following provides the most valid approach to implement the integration?

# Options
1. Use an IAM policy that references the LDAP identifiers and AWS credentials.
2. Use IAM roles to rotate the IAM credentials whenever LDAP credentials are updated.
3. Develop an on-premises custom identity broker application and use STS to issue short-lived AWS credentials.
4. Use AWS IAM Identity Center to manage access between AWS and your LDAP.

# Explanation
Without SAML support, a custom identity broker that authenticates against LDAP and calls STS for short-lived AWS credentials is the standard pattern. IAM Identity Center primarily supports SAML 2.0 IdPs. IAM policies alone cannot integrate LDAP. Manually rotating IAM credentials is not optimal.
