# Scenario
EC2 instances require access to various AWS services, such as Amazon S3 and Amazon Redshift. The company must provide access to system administrators so they can deploy and test changes.

# Question
Which configuration should be used to ensure that access to the resources is secured and not compromised? (Select TWO.)

# Options
1. Enable Multi-Factor Authentication.
2. Store the AWS Access Keys in ACM.
3. Assign an IAM role to the EC2 instance.

# Explanation
MFA secures administrator console access. An IAM role attached to the EC2 instance allows the application on the instance to access AWS services without storing credentials. ACM is for SSL/TLS certificates, not for storing access keys.
