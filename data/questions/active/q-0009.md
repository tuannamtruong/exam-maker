# Scenario
EC2 instances require access to various AWS services, such as S3 and Redshift. The company must provide access to system administrators so they can deploy and test changes.

# Question
Which configuration should be used to ensure that access to the resources is secured and not compromised? (Select TWO.)

# Options
1. Enable Multi-Factor Authentication.
2. Store the AWS Access Keys in ACM.
3. Assign an IAM role to the EC2 instance.

# Explanation
2. ACM is just a service that lets you easily provision, manage, and deploy public and private SSL/TLS certificates for use with AWS services and your internal connected resources. It is not used as a secure storage for your access keys.
