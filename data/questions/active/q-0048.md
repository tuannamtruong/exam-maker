# Scenario
A DevOps engineer is designing a highly scalable and resilient architecture to process images uploaded by users. The workflow requires that upon upload, each image is resized into multiple formats and then archived. The volume of uploads is highly variable, ranging from a few per hour to thousands per second.

# Question
Which combination of AWS services should the engineer use to provide the most scalable and decoupled solution for this workflow? (Select THREE.)

# Options
1. Amazon S3
2. Amazon SQS
3. AWS Lambda
4. Amazon Kinesis Data Streams

# Explanation
Amazon S3 stores the uploaded images and emits a PutObject event to start the workflow; an Amazon SQS queue decouples upload from processing for resilience and buffering; and AWS Lambda scales automatically to run the resizing logic per message. Kinesis Data Streams is for ordered, real-time streaming with multiple consumers — for independent job-based work, SQS is simpler and more cost-effective.
