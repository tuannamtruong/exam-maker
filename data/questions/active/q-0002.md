# Scenario
A game development company uses various RESTful web APIs hosted on their on-premises data center. They want to migrate to AWS Cloud to scale out their resources as well as to minimize costs.

# Question
Which solution best fits the migration goal?

# Options
1. Use AWS Lambda and API Gateway.
2. Set up a micro-service architecture with ECS, ECR, and Fargate.

# Explanation
Lambda + API Gateway is the 'gold standard' for modern serverless web APIs because of its extreme scalability and low cost for irregular traffic. ECS, ECR, and Fargate alone is not as scalable for this scenario and incurs more cost when traffic is irregular.
