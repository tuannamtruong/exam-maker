# Scenario
An organization uses Cloud Development Kit to define the infrastructure and deploys it through a pipeline using CodePipeline and CodeBuild.

The company wants to include unit tests in the pipeline to check the infrastructure configurations. The deployment should proceed only if all tests are successful.

# Question
Which steps should be implemented to enforce unit testing in the pipeline? (Select TWO.)

# Options
1. Develop a test utilizing the CDK assertions module, specifically using the template.hasResourceProperties assertion to verify that resources are configured with the expected properties.
2. Modify the CodeBuild build phase commands to execute the tests before deploying the application. Configure the OnFailure phase property to ABORT.
3. Update the CodeBuild build phase commands to run cdk synth and test using cdk deploy with the --no-execute flag to validate resources without performing the actual deployment.
4. Modify the CodeBuild build phase commands to execute the tests before deploying the application, and include the --rollback true flag in the cdk deploy command.
5. Create a separate test phase in the pipeline to run CDK unit tests. Configure CodePipeline to proceed to the deployment phase only if the test phase succeeds.

# Explanation
The CDK assertions module is a library that allows developers to write unit tests for CDK applications. It provides methods like template.hasResourceProperties to validate resource configurations, ensuring the infrastructure code is correct before deployment.

Modifying the CodeBuild build phase commands to run tests before deploying the application and setting the OnFailure property to ABORT ensures that if tests fail, the deployment process stops, preventing untested or misconfigured infrastructure from being deployed. 
Writing unit tests using the CDK assertions module, including testing resource properties with template.hasResourceProperties, checks the CloudFormation templates generated by the CDK, ensuring that the infrastructure matches the expected configurations.
