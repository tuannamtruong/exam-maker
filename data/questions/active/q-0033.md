# Scenario
A company wants to enforce column-level access control on tables in its data lake.

# Question
Which AWS service provides column-level access control?

# Options
1. AWS Glue
2. AWS Glue Elastic Views
3. AWS Lake Formation
4. Amazon EMR

# Explanation
AWS Lake Formation provides fine-grained access control — including row-, column-, and cell-level security — on tables registered with the Glue Data Catalog. Glue itself handles ETL and the catalog but not fine-grained access; Elastic Views was for materialized cross-store views; EMR is a managed big-data platform.
