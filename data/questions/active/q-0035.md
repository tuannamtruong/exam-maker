# Scenario
A company stores records in Amazon S3 and wants to run analytical queries against them in the most cost-effective way.

# Question
Which solution is most cost-effective?

# Options
1. Use an AWS Glue crawler to build tables in the AWS Glue Data Catalog, then query with Amazon Athena.
2. Stream the data through Kinesis Data Streams + Kinesis Data Analytics.
3. Load the data into Amazon OpenSearch Service.
4. Load the data into an Amazon Redshift cluster.

# Explanation
Glue Crawler + Athena is serverless and pay-per-query against data already in S3 — no cluster to keep running. Kinesis is for streaming, not batch S3 analysis. OpenSearch and Redshift require always-on clusters and data loading.
