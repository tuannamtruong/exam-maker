# Scenario
A SaaS application runs on multiple independent environments:
- Multiple ALBs
- Each ALB has its own ASG
- Each ASG has its own EC2 fleet

Requirements:
- Source is CodeCommit
- No build stage
- One commit triggers deployment to all environments simultaneously
- Least configuration

# Options
1. Create a single CodePipeline pipeline that deploys the application in parallel using unique CodeDeploy applications and deployment groups created for each ALB-ASG pair.
2. Create a single CodePipeline pipeline that deploys the application using a single CodeDeploy application and single deployment group.
3. Create a single CodePipeline pipeline that deploys the application in parallel using a single CodeDeploy application and unique deployment group for each ALB-ASG pair.

# Explanation
A deployment group contains EC2 instances (or ASGs), a load balancer, and deployment settings. 
A deployment group represents one deployment target.
CodePipeline supports parallel actions.
