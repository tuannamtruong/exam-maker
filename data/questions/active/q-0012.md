# Scenario
A Solutions Architect needs to launch a web application that will be served globally using CloudFront. The application is hosted on an EC2 instance which will be configured as the origin server to process and serve dynamic content.

# Question
Which option provides high availability for the application?

# Options
1. Provision two EC2 instances deployed in different AZs and configure them to be part of an origin group.
2. Launch an ASG of EC2 instances and configure it to be part of an origin group.
3. Use Lambda@Edge to improve the performance of your web application and ensure high availability. Set the Lambda@Edge functions to be part of an origin group.

# Explanation
CloudFront origin groups require at least two origins for failover. Deploy two EC2 instances in different AZs and put them in an origin group. You cannot use a single ASG directly as an origin, nor put Lambda@Edge functions into an origin group.
