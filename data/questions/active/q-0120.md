# Scenario
access to Session Manager should be limited solely through a private network.

# Question
TWO

# Options
1. Enable incoming traffic to TCP port 22 from the VPC CIDR range in all associated security groups of EC2 instances.
2. Launch a new EC2 instance that will function as a bastion host for the other EC2 instances in the fleet.
3. Provision a VPC endpoint for Systems Manager in the designated region.
4. Create an IAM instance profile to be associated with the fleet of EC2 instances and attach an IAM policy with the required Systems Manager permissions.

# Explanation
1. Session Manager will work without the need to open inbound ports.
2. a bastion host will not meet the requirement as it will still use SSH key pairs to remote access.
