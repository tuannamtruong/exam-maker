# Scenario
A solutions architect is writing an AWS Lambda function that will process encrypted documents from an FSx for NetApp ONTAP file system. The documents are protected by an AWS KMS customer key. After processing, the function will store results in an S3 bucket with the S3 Glacier Flexible Retrieval storage class. The function must be able to decrypt the files.

# Question
Which action accomplishes the requirement?

# Options
1. Attach the kms:decrypt permission to the Lambda function's execution role. Add a statement to the AWS KMS key's policy that grants the function's execution role the kms:decrypt permission.
2. Attach the kms:decrypt permission to the Lambda function's execution role. Add a statement to the AWS KMS key's policy that grants the function's ARN the kms:decrypt permission.

# Explanation
AWS Lambda interacts with other AWS services using the permissions associated with its execution role. The KMS key policy must grant the execution role (not the function ARN) the kms:decrypt permission.
