# Scenario
A company runs multiple ECS services behind an ALB.

Requirements:

Collect application logs
Collect ALB access logs
Store everything in S3
Application logs should arrive in near real time for analysis.

# Question
(Select THREE.)

# Options
1. Download the CloudWatch Logs container instance from AWS. Configure this instance as a task. Update the application service definitions to include the logging task.
2. Install the CloudWatch Logs agent on the ECS instances. Change the logging driver in the ECS task definition to awslogs.
3. Use EventBridge to schedule a Lambda function that will run every 60 seconds and will run the CloudWatch Logs create-export-task command. Then point the output to the logging S3 bucket.
4. Activate access logging on the ALB. Then point the ALB directly to the logging S3 bucket.
5. Activate access logging on the target groups that the ECS services use. Then send the logs directly to the logging S3 bucket.
6. Create a Kinesis Data Firehose delivery stream that has a destination of the logging S3 bucket. Then create a CloudWatch Logs subscription filter for Kinesis Data Firehose.

# Explanation
1. There is no "CloudWatch Logs container instance".

3. It is not near real time.

5. Target groups do not produce access logs.
