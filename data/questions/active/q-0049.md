correct: 1,2,3

# Scenario
A DevOps engineer is using AWS Backup to create a centralized backup policy for an organization's resources, including EBS volumes and RDS databases. The policy must create daily backups at 2 AM UTC, retain them for 30 days, and copy them to a secondary region for disaster recovery.

# Question
Which components must be configured in the backup plan to achieve this? (Select THREE.)

# Options
1. A backup rule that defines the backup frequency and window
2. A lifecycle rule to manage the retention period of the backups
3. A copy action to replicate the backups to another region
4. A resource assignment that specifies which AWS services to back up
5. A backup vault with AWS KMS encryption enabled

# Explanation
The backup rule is a core component of a backup plan. It specifies the schedule for when backup jobs are created (such as daily at 2 AM UTC) and the backup window during which the job will start. This directly addresses the scheduling requirement.

The lifecycle settings within the backup rule define how long recovery points are retained and, optionally, when they transition to cold storage. For a 30-day retention requirement, you configure the lifecycle to expire (delete) recovery points after 30 days (and optionally transition them earlier to a colder tier).

A copy action is configured within the backup rule to create a copy of the backup in a different AWS region. This is the mechanism used to fulfill the disaster recovery requirement of having backups available in a secondary location.

4. Resource assignments are used to specify which individual resources should be backed up by the plan. This does not define the schedule, retention, or replication policy itself. It determines the scope of what the plan applies to.
5. A backup vault is the container where the backups are stored. While creating and securing a vault is a necessary part of the overall setup, the backup plan itself contains the rules for schedule, retention, and replication. The vault is the destination, not the policy definition.
