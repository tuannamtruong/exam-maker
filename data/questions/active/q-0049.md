# Scenario
A DevOps engineer is using AWS Backup to create a centralized backup policy for an organization's resources, including EBS volumes and RDS databases. The policy must create daily backups at 2 AM UTC, retain them for 30 days, and copy them to a secondary region for disaster recovery.

# Question
Which components must be configured in the backup plan to achieve this? (Select THREE.)

# Options
1. A backup rule that defines the backup frequency and window
2. A lifecycle rule to manage the retention period of the backups
3. A copy action to replicate the backups to another region
4. A resource assignment that specifies which AWS services to back up
5. A backup vault with AWS KMS encryption enabled

# Explanation
Within a backup plan, the backup rule sets the schedule/window (daily at 2 AM UTC), the lifecycle settings expire recovery points after 30 days, and a copy action replicates backups to another Region for DR. A resource assignment only defines the scope of what is backed up, and a backup vault is just the storage destination — neither defines the schedule, retention, or replication policy.
