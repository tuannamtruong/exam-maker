# Scenario
ECS Fargate
recommended way of updating the platform version of the service on the AWS Console?

# Options
1.	Update the task definition with the new platform version ARN so that ECS re-deploys the cluster with the new platform version. 
2.	Update the service on ECS and select “Redeploy” on the deployment strategy so that the cluster will be re-deployed with the new platform version. 
3.	Update the service on ECS and select “Force new deployment” so that the cluster will be re-deployed with the new platform version. 
4.	Enable the automatic platform version upgrade feature in ECS.

# Explanation
1. because modifying the task definition will cause a new version to be deployed, but since the ARN or the image revision did not change, no further deployments will be made by ECS.
2. because there is no “Redeploy” deployment strategy option in ECS.
4. because there is no such feature in Amazon ECS.
