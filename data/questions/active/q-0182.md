# Scenario
CodeDeploy and CloudFormation. During the deployment window, the application must be highly available and CodeDeploy must shift 10% of traffic to a new version of the application every minute until all traffic is shifted.

# Question
Which configuration should the DevOps engineer add in the CloudFormation template to meet these requirements?

# Options
1. Add an AppSpec file with the CodeDeployDefault.ECSLinear10PercentEvery1Minutes deployment configuration.
2. Add the AWS::CodeDeployBlueGreen transform and the AWS::CodeDeploy::BlueGreen hook parameter with the CodeDeployDefault.ECSLinear10PercentEvery1Minutes deployment configuration.
3. Add an AppSpec file with the ECSCanary10Percent5Minutes deployment configuration.
4. Add the AWS::CodeDeployBlueGreen transform and the AWS::CodeDeploy::BlueGreen hook parameter with the ECSCanary10Percent5Minutes deployment configuration.

# Explanation
1. CloudFormation's native ECS blue/green deployment feature does not use an AppSpec file.
3. Same as 1 and uses canary deploy.
4. CFN hook is correct, but ECSCanary10Percent5Minutes is wrong. Canary is wrong.
