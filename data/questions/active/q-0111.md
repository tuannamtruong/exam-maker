# Scenario
connected to their AWS VPC via a Direct Connect connection
50-TB digital videos and media files that are stored on their on-premises tape library
catalog system that will enable them to search their files using facial recognition.
migrate these media files to AWS including the MAM video contents.

# Question
LEAST amount of ongoing management overhead and will cause MINIMAL disruption to the existing system?

# Options
1. Connect the on-premises file system to Storage Gateway by setting up a file gateway appliance on-premises. Use the MAM solution to extract the media files from the current data store and send them into the file gateway. Populate a collection using Rekognition by building a catalog of faces from the processed media files. Launch a Lambda function to invoke Rekognition Javascript SDK to have it fetch the media files from the S3 bucket which is backing the file gateway. Retrieve the needed metadata using the Lambda function and store the information into the MAM solution.
2. Launch a tape gateway appliance in your on-premises data center and connect it to your Storage Gateway service. Set up the MAM solution to fetch the media files from the current archive and store them into the tape gateway in the AWS Cloud. Build a collection from the catalog of faces using Rekognition. Set up a Lambda function which invokes the Rekognition Javascript SDK to have Rekognition process the video directly from the tape gateway in real-time. Retrieve the required metadata and store them into the MAM solution.

# Explanation
A file gateway presents the media files through a local file share while backing them with an S3 bucket, so Rekognition can fetch and process them directly from S3 with the least ongoing management overhead and minimal disruption to the existing system.

2. Although this is using the right combination of Storage Gateway and Rekognition, take note that you can't directly fetch the media files from your tape gateway in real-time since this is backed up using Glacier. Although the on-premises data center is using a tape gateway, you can still set up a solution to use a file gateway in order to properly process the videos using Rekognition. Keep in mind that the tape gateway in Storage Gateway service is primarily used as an archive solution.
