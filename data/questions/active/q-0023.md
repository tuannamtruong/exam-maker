# Scenario
A company needs to configure its EC2 instances without having to establish an RDP or SSH connection to each instance.

# Question
What can be used to configure the EC2 instances?

# Options
1. AWS Config
2. AWS CodePipeline
3. Run Command
4. EC2Config

# Explanation
AWS Systems Manager Run Command lets you remotely and securely manage the configuration of managed instances at scale without SSH/RDP.
