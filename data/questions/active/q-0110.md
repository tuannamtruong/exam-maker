# Scenario
CI/CD process using GitHub, CodeBuild, CodeDeploy, and CodePipeline. all files must remain in the same region.

# Question
MOST suitable and efficient solution?

# Options
1. Create a new pipeline using CodePipeline and a GitHub repository as the source on multiple regions. Configure the repository of the pipeline for each region to trigger the build and deployment actions whenever there is a new code update. The pipeline will automatically store output files on a default artifact bucket on each region.
2. Create a new pipeline using CodePipeline and a GitHub repository as the source in your primary region. Set a CodeBuild test action to run the automated unit and integration tests. Configure the repository to trigger the build and deployment actions whenever there is a new code update. Using the Management Console, set up the pipeline to use cross-region actions that will run the build and deployment actions to other regions. Manually configure the pipeline to automatically store output files on a single S3 bucket.
3. Create a new pipeline using CodePipeline and a GitHub repository as the source in your primary region. Configure the repository to trigger the build and deployment actions whenever there is a new code update. Using the Management Console, set up the pipeline to use cross-region actions that will run the build and deployment actions to other regions. The pipeline will automatically store output files on a default artifact bucket on each region.

# Explanation
1. this deployment setup is not efficient since you have to maintain several pipelines in multiple regions. A better solution would be to simply configure cross-region actions to build and deploy the application on multiple regions.
2. this will typically violate the data residency requirement. Take note that the application libraries and game user data must remain in the same region.
