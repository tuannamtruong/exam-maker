# Scenario
A requirement to create a simple web page hosted on an S3 bucket that displays the status of the EC2 instances in the fleet. This web page must be updated whenever a new instance is launched or terminated. Additionally, a searchable log of these events is required for review at a later time.

# Options
1. Create an EventBridge rule for the scale-in/scale-out event and deliver these logs to CloudWatch Logs. Manually export the CloudWatch Log group to the S3 bucket to view them.
2. Create an EventBridge rule for the scale-in/scale-out event and create two targets for the event – one target to the webpage S3 bucket and another to deliver event logs to CloudWatch Logs.
3. Write your Lambda function to update the simple webpage on S3 and send event logs to CloudWatch Logs. Create an EventBridge rule to invoke the Lambda for scale-in/scale-out events.

# Explanation
1. you have to export the logs manually on an S3 bucket. This action is not recommended since you can simply use a Lambda function to log the changes of the EC2 instances to a file in the S3 bucket.
2. you cannot set an S3 bucket or object as a target for an EventBridge rule.
