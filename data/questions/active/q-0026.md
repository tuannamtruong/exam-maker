# Scenario
A distributed microservice-based serverless app has data retrieved and written from multiple DynamoDB tables. The architect must ensure efficient retrieval and writing of data without impacting baseline performance, while ensuring seamless access to patient information for healthcare professionals.

# Question
What is the MOST operationally efficient solution?

# Options
1. Launch AWS Lambda functions with an edge-optimized API Gateway.
2. Utilize AWS AppSync pipeline resolvers.
3. Set up DynamoDB connector for Athena Federated Query.
4. Use CloudFront functions.

# Explanation
AppSync pipeline resolvers aggregate data from multiple data sources (multiple DynamoDB tables) with a single GraphQL call, supporting both reads and writes. Lambda + API Gateway improves edge latency but doesn't simplify multi-table access. Athena Federated Query is read-only and stores results in S3.
