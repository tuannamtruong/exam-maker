# Scenario
AWS::AutoScaling::AutoScalingGroup options

# Options
1. AutoScalingRollingUpdate
2. AutoScalingReplacingUpdate
3. AutoScalingInplaceUpdate
4. AutoScalingScheduledAction

# Explanation
| Policy                       | Action                      | Downtime | Typical use                    |
| `AutoScalingRollingUpdate`   | Replace instances gradually | Minimal  | Normal AMI/application updates |
| `AutoScalingReplacingUpdate` | Replace entire ASG          | Possible | Major changes                  |
| `AutoScalingScheduledAction` | Protect scheduled scaling   | None     | ASGs using scheduled scaling   |
