# Scenario
A company has:

Control Tower
Organizations
Multiple member accounts

Requirements:

Demonstrate compliance with CIS AWS Foundations Benchmark
Aggregate Security Hub findings centrally
Only the security team can see organization-wide findings
Individual account users can still view findings in their own accounts
New accounts must automatically be enrolled in Security Hub

# Question
Which THREE actions meet these requirements with the most automation? (Select THREE.)

# Options
1. Enable trusted access for Security Hub. Create a dedicated security account. Configure it as the Security Hub delegated administrator. Enable the CIS AWS Foundations standard in that account.
2. Enable trusted access. Enable the CIS standard from the management account.
3. Create an IAM Identity Center permission set. Assign the security team to the delegated administrator account.
4. Create an SCP denying Security Hub access to everyone except the security team.
5. Enable automatic account enrollment in Security Hub.
6. Use EventBridge and Lambda to call CreateMembers whenever Control Tower creates an account.

# Explanation
1 -> Aggregate Security Hub findings centrally.
3 -> Only the security team can view organization-wide findings.
5 -> New accounts must automatically be enrolled.

2. The management account should not act as the Security Hub administrator.
4. An SCP is much too broad.
6. This used to be necessary before organization integration. Today Security Hub supports automatic onboarding.
