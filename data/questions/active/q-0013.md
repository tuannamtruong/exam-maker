# Scenario
A software development company has hundreds of EC2 instances with multiple ALBs across multiple AWS Regions. The public applications hosted in their EC2 instances are accessed from their on-premises network. The company needs to reduce the number of IP addresses it must regularly whitelist on the corporate firewall device.

# Question
Which approach can be used to fulfill this requirement?

# Options
1. Use AWS Global Accelerator and create multiple endpoints for all the available AWS Regions. Associate all the private IP addresses of the EC2 instances to the corresponding endpoints.
2. Launch a NLB with an associated Elastic IP address. Set the ALBs in multiple Regions as targets.
3. Use AWS Global Accelerator and create an endpoint group for each AWS Region. Associate the ALB from each region to the corresponding endpoint group.

# Explanation
Global Accelerator provides two static anycast IPs you can whitelist once. Create one endpoint group per region and associate the regional ALB(s) with it. You associate ALBs, not raw EC2 IPs. NLB cannot target ALBs across regions.
