# Scenario
A company deployed AWS resources by using an AWS CloudFormation template. The template specified only the properties necessary for the resource creation. The template inherited the default values for the remaining optional properties. To deploy the workload with proper configuration, the company had to reconfigure the default values outside of CloudFormation. The reconfiguration led to configuration inconsistencies.
The company wants to maintain all the settings for the properties through the template. The company wants to identify any changes made outside of CloudFormation and remediate the template back to the original configuration.

# Question
LEAST implementation effort?

# Options
3) Update the template to specify resource configuration values for all properties, including default values. Use the cloudformation-stack-drift-detection-check AWS Config rule. Configure the rule’s automatic remediation action to run the AWS-UpdateCloudFormationStack AWS Systems Manager Automation runbook.
4) Use the cloudformation-stack-drift-detection-check AWS Config rule. Configure the rule’s automatic remediation action to run the AWS-UpdateCloudFormationStack AWS Systems Manager Automation runbook.

# Explanation
3. The CloudFormation drift detection feature can identify stack resources that have had configuration changes outside of CloudFormation. AWS Config can initiate CloudFormation drift detection, and you can add an automatic remediation action to the AWS Config rule. You must explicitly specify a property value, even if it is the default value, to have CloudFormation track a resource property to determine drift. In this solution, you use CloudFormation to explicitly specify all resource properties. You maintain all the settings for the properties through CloudFormation. This solution also requires the least implementation effort because it does not require a separate Lambda function. 

4. You must explicitly specify a property value, even if it is the default value, to have CloudFormation track a resource property to determine drift. You must specify all resource properties by using CloudFormation. Otherwise, CloudFormation cannot maintain all the properties of the settings.
