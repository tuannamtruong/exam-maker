# Scenario
A team wants to transfer data between EC2 instances in two different VPCs without traversing the public internet.

# Question
Which combination of actions should be taken? (Select TWO.)

# Options
1. Set up a VPC peering connection between the VPCs.
2. Create an Egress-only Internet Gateway.
3. Launch a NAT Gateway in the public subnet of each VPC.
4. Deploy a VPC endpoint on each region to enable a private connection.
5. Re-configure the route table's target and destination of the instances' subnet.

# Explanation
A VPC peering connection plus updated route tables routes inter-VPC traffic privately. Egress-only IGW is for IPv6 outbound. NAT Gateway sends traffic to the public internet. VPC endpoints don't support cross-region private communication.
