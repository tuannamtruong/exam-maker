# Scenario
The pipeline contains a source stage, a build stage, and a deploy stage. The pipeline also has a CodeStar connection to the GitHub code repository.
The build project needs to perform a git clone of the repository as part of the build process. source stage is working properly. However, the build stage fails each time the pipeline runs.

# Question
What is the reason that the build stage fails in the pipeline?

# Options
1. The build stage within the pipeline needs to use the CodeStar connection action.
2. The CodeStar connection to GitHub contains incorrect credentials.
3. The CodePipeline service role does not have permission to use the CodeStar connection.
4. The CodeBuild service role does not have permission to use the CodeStar connection.

# Explanation
When CodeBuild performs its own git clone, it independently accesses GitHub through the CodeStar connection. The CodeBuild service role must be allowed to use that connection.

1. There is no CodeStar Connection build action.
2. If the credentials were wrong, the source stage would also fail.
3. The source stage already succeeds.
