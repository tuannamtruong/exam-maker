# Scenario
An organization stores critical files in an S3 bucket in the us-east-1 region and requires these files to be replicated to a secondary bucket in the us-west-2 region for disaster recovery purposes. Cross-region replication has been configured to ensure that all objects and their metadata are available in both regions. Despite this setup, some objects occasionally fail to replicate due to transient errors.
All the objects and object metadata from both regions must be accessible to each application.

A DevOps engineer has been assigned to create a solution that automates retries for objects that fail to replicate.

# Question
What solution requires the LEAST operational overhead while meeting the specified requirements?

# Options
1. Configure an SQS queue to receive S3 replication failure notifications via S3 Event Notifications. Create a Lambda function to process these notifications from the queue and re-upload the failed objects using s3.putObject() command to the destination bucket.
2. Create a Lambda Function that re-uploads failed replication objects using the s3.putObject() command to the destination bucket. Configure an EventBridge rule that listens to S3 Event Notifications for failed replication events and triggers the Lambda Function.
3. Configure an S3 event notifications to trigger a Lambda function upon replication failures. Configure the Lambda function to utilize S3 batch operations to retry the replication of failed objects.

# Explanation
S3 Batch Operations allow you to perform actions like copying, tagging, or deleting objects across multiple S3 objects with a single API call or console action.
S3 event notification, any replication failures can automatically trigger a Lambda function without manual intervention.

1. introduces additional components (SQS), which increases the operational overhead.
2. Unnecessary complexity, and this approach is less efficient because it handles each failed replication individually rather than in batches, increasing the complexity and resource consumption.
