# Scenario
A company has an application hosted in an ECS Cluster behind an ALB. The Solutions Architect is building a web filtering solution that allows or blocks web requests based on the country that the requests originate from. However, the solution should still allow specific IP addresses from that country.

# Question
Which combination of steps satisfies this requirement? (Select TWO.)

# Options
1. Add another rule in the AWS WAF web ACL with a geo match condition that blocks requests that originate from a specific country.
2. Using AWS WAF, create a web ACL with a rule that explicitly allows requests from approved IP addresses declared in an IP Set.
3. Set up a geo match condition in the ALB that blocks requests from a specific country.

# Explanation
AWS WAF supports geo-match conditions combined with IP set allow rules. CloudFront geo restriction blocks requests before WAF sees them, so use WAF geo match instead. ALB doesn't support geo match conditions.
