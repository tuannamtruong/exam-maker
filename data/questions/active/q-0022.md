# Scenario
A company wants to scale the throughput of its AWS Site-to-Site VPN connections.

# Question
Which solution should the architect carry out?

# Options
1. Re-route some of the VPN connections to a secondary customer gateway device on the remote network's end.
2. Associate the VPCs to an Equal Cost Multipath Routing (ECMP)-enabled transit gateway and attach additional VPN tunnels.
3. Add more virtual private gateways to a VPC and enable Equal Cost Multipath Routing (ECMP) to get higher VPN bandwidth.
4. Modify the VPN configuration by increasing the number of tunnels to scale the throughput.

# Explanation
Transit Gateway supports ECMP across multiple VPN tunnels, scaling throughput beyond the 1.25 Gbps per-tunnel limit. A VPC can only have one VGW. A VPN connection is capped at 2 tunnels. Adding a secondary customer gateway adds redundancy, not throughput.
