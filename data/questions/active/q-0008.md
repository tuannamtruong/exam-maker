# Scenario
A telecommunications company is planning to grant AWS Console access to its developers. Company policy requires the use of identity federation and role-based access control. Currently, the roles are already assigned via groups in the corporate Active Directory.

# Question
What combination of the following services can provide developers access to the AWS console? (Select TWO.)

# Options
1. AWS Directory Service Simple AD
2. AWS Directory Service AD Connector
3. IAM Groups
4. IAM Roles

# Explanation
AD Connector is a directory gateway that redirects directory requests to your on-premises Microsoft Active Directory. IAM Roles allow federated users (mapped from AD groups) to assume permissions. Simple AD doesn't connect to on-prem AD. IAM Groups are just collections of users — not used for federation.
