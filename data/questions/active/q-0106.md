# Scenario
An application is hosted on EC2 deployed across multiple Availability Zones using an ALB. The instances in one Availability Zone are experiencing issues. You need to isolate the impacted instances and use failover mechanisms to direct traffic to healthy zones.

# Question
Solution?

# Options
1. Disable Cross-Zone Load Balancing on the ALB and use Route 53 Application Recovery Controller to initiate a zonal shift to avoid the impacted zone entirely.
2. Implement auto-scaling policies to automatically replace unhealthy instances within the affected zone.

# Explanation
Route 53 ARC allows you to implement highly reliable routing controls to manage traffic during application recovery scenarios. These routing controls act as simple on/off switches hosted on a high-availability cluster. The cluster provides five redundant Regional endpoints, enabling API calls to manage the state of the routing controls. To handle failover, you can set one routing control to ON and another to OFF. This action reroutes traffic from the impacted Availability Zone to a healthy one, ensuring continuous application availability.

2. Although it usually helps maintain the number of instances, it doesn't directly address the need to reroute traffic away from the unhealthy zone. It focuses more on instance replacement rather than traffic management.
