# Scenario
A business plans to deploy an application on EC2 instances within a VPC and is considering adopting a NLB to distribute incoming traffic. A solutions architect needs to suggest a solution that enables the security team to inspect traffic entering and exiting their VPC.

# Question
Which solution should be implemented?

# Options
1. Create a firewall using the AWS Network Firewall service at the VPC level then add custom rule groups for inspecting ingress and egress traffic. Update the necessary VPC route tables.
2. Enable Traffic Mirroring on the NLB and forward traffic to the instances. Create a traffic mirror filter to inspect the ingress and egress of data that traverses your VPC.
3. Create a firewall at the subnet level using the Detective service. Inspect the ingress and egress traffic using the VPC Reachability Analyzer.
4. Use the Network Access Analyzer service on the application's VPC for inspecting ingress and egress traffic. Create a new Network Access Scope to filter and analyze all incoming and outgoing requests.

# Explanation
2. this alone accomplishes nothing. It would make more sense if you redirect the traffic to an EC2 instance where an Intrusion Detection System (IDS) is running. Remember that Traffic Mirroring is simply an VPC feature that you can use to copy network traffic from an elastic network interface. Traffic mirror filters can’t inspect the actual packet of the incoming and outgoing traffic.
3. a firewall must be created at the VPC level and not at the subnet level. Moreover, Detective can’t be used to create a firewall. This service just automatically collects log data from your AWS resources to analyze, investigate, and quickly identify the root cause of potential security issues or suspicious activities in your AWS account. For this scenario, you have to use the AWS Network Firewall instead.
4. Network Access Analyzer is a feature of VPC that reports on unintended access to your AWS resources based on the security and compliance that you set. This service is not capable of performing deep packet inspection on traffic entering or leaving your VPC, unlike AWS Network Firewall.
