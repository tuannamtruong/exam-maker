# Scenario
A company has multiple AWS accounts and wants a solution that centrally manages their AWS resources, allows central procurement, and shares resources across accounts.

# Question
Which combination of services should be used? (Select TWO.)

# Options
1. Use AWS Control Tower to easily and securely share your resources with your AWS accounts.
2. Use the AWS Identity and Access Management service to set up cross-account access that will easily and securely share your resources with your AWS accounts.
3. Use the AWS Resource Access Manager (RAM) service to easily and securely share your resources with your AWS accounts.
4. Consolidate all of the company's accounts using AWS Organizations.

# Explanation
AWS Resource Access Manager (RAM) is the service for sharing AWS resources across accounts. AWS Organizations consolidates the accounts so resources can be procured centrally. IAM cross-account access is about access control, not resource sharing.
