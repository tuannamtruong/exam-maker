# Scenario
A company uses:

Organizations
Control Tower
Account Factory

Whenever a new AWS account is created through Account Factory, the company wants to automatically:

deploy CloudFormation resources
apply OU/account-specific SCPs
without manual intervention

# Options
1. Use Service Catalog with Control Tower. Create portfolios and products in Service Catalog. Grant granular permissions to provision these resources. Deploy SCPs by using the CLI and JSON documents.
2. Deploy CloudFormation stack sets by using the required templates. Enable automatic deployment. Deploy stack instances to the required accounts. Deploy a CloudFormation stack set to the organization’s management account to deploy SCPs.
3. Create an EventBridge rule to detect the CreateManagedAccount event. Configure Service Catalog as the target to deploy resources to any new accounts. Deploy SCPs by using the CLI and JSON documents.
4. Deploy the Customizations for AWS Control Tower (CfCT) solution. Use a CodeCommit repository as the source. In the repository, create a custom package that includes the CloudFormation templates and the SCP JSON documents.

# Explanation
CfCT was created specifically to solve this problem:

automatically reacts to new Control Tower accounts
deploys CloudFormation templates
deploys SCPs
supports OU-specific and account-specific customizations
integrates directly with Control Tower lifecycle events
stores templates and configuration in a Git repository (CodeCommit or other supported source)

The repository contains:

CloudFormation templates
SCP JSON documents
manifest/configuration describing which OU/account receives which customization

1. Service Catalog is already part of Account Factory. 
However, Service Catalog provisions products only when requested. It is not the mechanism for organization-wide automatic customization after account creation, and SCP deployment via the CLI is manual automation.
2. StackSets can deploy CloudFormation automatically to new accounts, target OUs, and automatically deploy when new accounts join an OU. 
However, StackSets cannot deploy SCPs — SCPs are Organizations resources.
3. This is a custom implementation. AWS already provides a managed solution (CfCT).
