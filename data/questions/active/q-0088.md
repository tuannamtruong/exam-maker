# Scenario
need for an effective method to update the DynamoDB table whenever an instance is created or terminated

# Options
1. Configure an EventBridge target for your ASG that will trigger a Lambda function when a lifecycle action occurs. Configure the function to update the DynamoDB table with the necessary instance details.
2. Define a Lambda function as a notification target for the lifecycle hook for the ASG. In the event of a scale-out or scale-in, the lifecycle hook will trigger the Lambda function to update the DynamoDB table with the necessary details.
3. Configure a CloudWatch alarm that will monitor the number of instances on your ASG and trigger a Lambda function to update the DynamoDB table with the necessary details.

# Explanation
2. you cannot use Lambda as a notification target for the lifecycle hook of an ASG. You can only configure EventBridge, SNS, or SQS as notification targets.

3. this option doesn't track the lifecycle action of the ASG. In this scenario, it's better to create a lifecycle hook integrated with EventBridge and Lambda instead.
