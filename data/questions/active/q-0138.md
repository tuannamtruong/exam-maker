# Scenario
Adding HTTP response headers such as X-Content-Type-Options, X-Frame-Options and X-XSS-Protection should be implemented to comply with the Open Web Application Security Project (OWASP) standards.

# Options
1. Host the application on an Amazon S3 bucket configured for website hosting. Set up an Amazon CloudFront web distribution and set the S3 bucket as the origin with the origin response event set to trigger a Lambda@Edge function. Add the required security headers in the HTTP response using the AWS Lambda function.
2. Host the application on an Amazon S3 bucket configured for website hosting. Set up an Amazon CloudFront web distribution and set the S3 bucket as the origin. Create and attach a Response Headers Policy to the CloudFront cache behavior that automatically adds the required security headers in the HTTP response.

# Explanation
1. While this method works, it only adds unnecessary complexity. Lambda@Edge requires extra setup, code, and management. CloudFront’s built-in Response Headers Policies now provide a more straightforward way to add security headers, making Lambda@Edge unnecessary for this case.
