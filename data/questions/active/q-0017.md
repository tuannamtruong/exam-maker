# Scenario
A digital company is using EC2 instances to host editing software that is remotely accessed by their teams. Due to licensing restrictions, the application cannot be deployed in the ap-southeast-1 (Singapore) region. A team based in the Philippines needs to access the application, requiring connectivity with latency in the single-digit millisecond range.

# Question
Which of the following solutions addresses these requirements?

# Options
1. Launch the applications in the ap-southeast-1 region. Then, use AWS Outposts to extend the company's VPC to an on-premises network in the Philippines.
2. Enable AWS Wavelength Zones within the ap-southeast-1 region. Extend the company's VPC to the selected Wavelength Zones and launch the applications in that zone.
3. Enable AWS Local Zones within the ap-southeast-1 region. Extend the company's VPC to the selected Local Zone and launch the applications in that zone.

# Explanation
AWS Local Zones place compute closer to end users for single-digit-ms latency for desktop-type workloads. Outposts requires shipping physical hardware. Wavelength is for 5G mobile workloads.
