# Scenario
A company utilizes AWS for its applications, where each application team has its own AWS account within an Organizations organization. To ensure adherence to security standards, the strict use of CloudFormation for every deployment is enforced to prevent misconfigurations. The production support team can resolve application-related issues by modifying resources through the Management Console.

A DevOps engineer is tasked with implementing a solution that promptly detects any AWS service misconfigurations leading to non-compliance. The solution must automatically remediate these issues within 15 minutes of identification and provide a centralized dashboard primarily focused on security findings, compliance, and actionable insights. The enforcement of common security standards such as CIS AWS Foundations Benchmark and AWS Foundational Security Best Practices Standard are not required.

# Question
Which solution will meet the requirements with the LEAST operational overhead?

# Options
1. Enable Config in each account and turn on the recorder to detect non-compliant resources. Use CloudWatch Logs filters for drift detection and Systems Manager for automatic remediation. Set up an organization-wide aggregator in Config using a delegated administrator account to provide a centralized dashboard.
2. Use CloudFormation StackSet to enable Config to all the accounts within the organization. Utilize Lambda and Systems Manager for automatic remediation. Designate a Security Hub administrator account and set up a centralized dashboard from the designated administrator account.
3. Enable Config in each account and turn on the recorder to detect non-compliant resources. Set up automatic remediations by deploying conformance packs throughout the organization. Set up an organization-wide aggregator in Config using a delegated administrator account to provide a centralized dashboard.
4. Use the CloudFormation stack set to enable Config to all the accounts within the organization. Configure automatic remediations by deploying conformance packs within the organization. Designate a Security Hub administrator account and set up a centralized dashboard from the designated administrator account. Disable the security standard option in Security Hub via the EnableSecurityHub API operation or the --no-enable-default-standards AWS CLI flag.

# Explanation
Auto-remediation (<=15 min)
Config + conformance packs + SSM automation -> built-in, low effort

Security Hub normally enables the default standards (CIS AWS Foundations Benchmark and AWS Foundational Security Best Practices). Since enforcing those standards is explicitly not required, they are turned off at enablement — via the EnableSecurityHub API operation or the --no-enable-default-standards AWS CLI flag.

1. CloudWatch Logs for drift detection -> incorrect approach

2. Using Lambda for remediation is unnecessary custom work and higher maintenance. It does not leverage conformance packs.

3. Uses Config + conformance packs -> good
Uses Config aggregator -> not ideal dashboard
Missing Security Hub requirement (security insights)
