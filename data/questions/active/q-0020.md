# Scenario
A company has microservices applications hosted on EC2 instances with Docker installed, ECS, and newer deployments are hosted on EKS. The company is using open-source tools such as Prometheus and Grafana installed on a virtual machine in its data center for monitoring its applications. Management wants to use the same tools for monitoring its containerized applications in its cloud environment.

# Question
Which of the following options is the recommended implementation for this scenario?

# Options
1. Create a workspace on AWS Managed Service for Prometheus to collect container metrics. Set this workspace as the data source in AWS Managed Grafana for monitoring and data visualization.
2. Create a new ECS cluster. Deploy the Prometheus and Grafana containers on this cluster for monitoring containerized workloads. Configure Prometheus for container metrics collection and Grafana for monitoring and data visualization.

# Explanation
AWS Managed Service for Prometheus + Managed Grafana keeps the same tooling without the overhead of provisioning and scaling your own clusters.
