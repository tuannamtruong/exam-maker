# Scenario
A CodePipeline performs:

CodeBuild compiles the application and runs unit tests.
CodeDeploy deploys to staging.
CodeDeploy deploys to production.

Before production deployment, the QA team wants to:

Inspect the build artifact.
Run a manual penetration test using an internal tool exposed through a REST API.
Only continue to production after QA has completed its review.

# Question
(Choose two.)

# Options
1. Insert a manual approval action between the test actions and deployment actions of the pipeline.
2. Modify the buildspec.yml file for the compilation stage to require manual approval before completion.
3. Update the CodeDeploy deployment groups so that they require manual approval to proceed.
4. Update the pipeline to directly call the REST API for the penetration testing tool.
5. Update the pipeline to invoke a Lambda function that calls the REST API for the penetration testing tool.

# Explanation
2. buildspec.yml only defines what CodeBuild executes. It has no capability to pause execution and wait for human approval.

3. CodeDeploy deployment groups do not support manual approval. 
Approvals belong in CodePipeline, not CodeDeploy.

4. CodePipeline cannot natively invoke arbitrary REST endpoints.
