# Scenario
A company has a separate AWS account where developers can freely spawn its AWS resources and test new builds. Given the lax restrictions in this environment, Trusted Advisor was checked, and it shows that several instances use the default security group rule that opens inbound port 22 to all IP addresses. Even for a test environment, port 22 access should be restricted to the public IP of the on-premises data center only. The company wants to be notified of any security check recommendations from Trusted Advisor and automatically resolve non-compliance based on the results.

# Question
What are the steps to set up the required solution? (Select THREE.)

# Options
1. Create a Config Cron job to schedule checks on all AWS security groups and send results to SNS for the non-compliance notification.
2. Set up custom Config rule that checks security groups to make sure that port 22 is not open to public. Send a notification to an SNS topic for non-compliance.
3. Set up a custom Config rule to execute a remediation action using Systems Manager Automation to update the security group rules for port 22 and restrict it to the office's public IP.
4. Create a Lambda function and integrate EventBridge and Lambda to execute the function on a regular schedule to check Trusted Advisor via API. Based on the results, publish a message to an SNS Topic to notify the subscribers.
5. Set up custom Config rule to execute a remediation action that triggers a Lambda function to update the publicly open port 22 in the security group and restrict to the office's public IP.
6. Create a Lambda function that executes every hour to refresh Trusted Advisor scan results via API. The automated notification on Trusted Advisor will notify of any changes.

# Explanation
1. you do not schedule Config with Cron jobs since this service can be configured to run periodically.

5. the custom remediation actions in Config is simply used in conjunction with Systems Manager Automation documents.

6. the notification is only sent on a weekly basis, which can be quite long if you are concerned about security issues.
