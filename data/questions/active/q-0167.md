# Scenario
A company uses:

AWS Organizations (all features enabled)
AWS Control Tower
Multiple OUs and accounts

The company wants to customize the Control Tower-managed AWS Config recorder in:
all existing accounts
all future enrolled accounts

# Question
automatically apply the customization whenever Control Tower enrolls or updates accounts. (THREE)

# Options
1.	Create a new AWS account. Create a Lambda function in the new account to apply the customizations. 
2.	Create a new AWS account as an AWS Config delegated administrator. Create a Lambda function there to apply the customizations only in the delegated administrator account. 
3.	Configure an EventBridge rule in the Control Tower management account that invokes a Lambda function when an OU is registered or re-registered. Re-register the root OU. 
4.	Configure the AWSControlTowerExecution IAM role in each account to be assumable by the Lambda function. Configure the Lambda function to assume the AWSControlTowerExecution role. 
5.	Create an IAM role in the Control Tower management account for the Lambda function. Grant that role permission to assume the AWSControlTowerExecution role in every account. 
6.	Configure an EventBridge rule in the Control Tower management account that invokes a Lambda function when an account is enrolled or updated in Control Tower or when the landing zone is updated. Re-register every OU.

# Explanation
5 -> The Lambda runs in the Control Tower management account. It needs permissions to reach every member account.

The automation must run:
- for existing accounts
- for newly enrolled accounts
- after landing zone updates

Control Tower emits EventBridge events such as:
- Account enrolled
- Account updated
- Landing zone updated

Those events should trigger the Lambda.
Re-registering every OU causes Control Tower to reapply governance to existing accounts, generating the necessary events.
This satisfies both existing and future accounts.

1. Control Tower automation belongs in the management account. There is no benefit to hosting the Lambda elsewhere.

2. AWS Config delegated administrator is useful for: organization Config rules, aggregators, organization conformance packs.
It is not used to modify each account's Control Tower-managed Config recorder.
Also, the option only modifies the delegated administrator account.

3. The trigger is wrong.
