# Scenario
solution is to take an Amazon EBS snapshot of the volume of the instance every day.

# Question
EASIEST?

# Options
1.	Create an Amazon EventBridge rule that is scheduled every midnight. Set the target to an AWS Lambda function that will run the EBS Create Snapshot to your defined EBS volumes. 
2.	Create an EventBridge rule that is scheduled every midnight. Set the target to an AWS Systems Manager Run command to run the EBS Create Snapshot call of the EBS volumes from inside the EC2 instance. 
3.	Create a script from inside the instance that will run the aws ec2 create-snapshot command. Schedule it to run every midnight using crontab. 
4.	Create an EventBridge rule that is scheduled to run at midnight. Set the target to directly call the EBS Create Snapshot to create a snapshot of the needed EBS volumes.
