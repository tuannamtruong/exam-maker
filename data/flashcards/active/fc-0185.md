# Front
Continuous infrastructure / tooling for containers: Karpenter, Proton, Prometheus — what's each for?

# Back
Karpenter: Kubernetes node autoscaler (right-sizes/just-in-time provisions nodes). 
Proton: managed templates/CI for container and serverless apps (platform team → dev self-service). 
Prometheus: metrics monitoring (pull-based time-series).
