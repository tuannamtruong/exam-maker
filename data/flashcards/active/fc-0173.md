# Back
Lifecycle “must wait” - IA: min 30 days.
Each S3 prefix can support:
3500 req per s for PUT/COPY/POST/DELETE
5500 req per s for GET
S3 Transfer Acceleration (S3TA) when you need to move large amounts of data over long geographical distances between your client and an S3 bucket.
Prerequisites when routing traffic using Route 53 to a website that is hosted in an S3 Bucket:
The S3 bucket name must be the same as the domain name.
A registered domain name.
S3 static website hosting
Bucket must be publicly readable
R53 Alias record (A/A4)
