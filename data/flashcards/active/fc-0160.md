# Back
TYPE
DESCRIPTION
A
Domain  IPv4
AAAA
Domain  IPv6
CNAME
Aliases one domain name to another.
DNS standard forbids CNAME at the apex because it would conflict with NS/SOA records.
ALIAS
Hostname -> AWS Resource
Looks like an A/AAAA record to clients
Behaves like a CNAME internally
MX
Directs email to mail servers.
NS
Specifies the authoritative nameserver for a domain.
SOA
Contains administrative information about the domain, like the primary nameserver and zone update settings.
TXT
Stores text information, often used for verification.
