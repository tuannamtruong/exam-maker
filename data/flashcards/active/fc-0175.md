# Back
Secure in-flight data between your application and Amazon RDS:
Configure your RDS instance to allow SSL/TLS connections. rds.force_ssl.
Use RDS-provided CA certificate.
Configure your application to connect using SSL/TLS.
Optionally use IAM authentication for token-based login.
Restrict access via VPC security groups.
