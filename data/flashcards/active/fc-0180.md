# Back
KMS, more control over access to data you encrypt. You can use the key management and cryptographic features directly in your applications or through AWS services that are integrated with AWS KMS. Enables you to maintain control over who can use your customer master keys and gain access to your encrypted data. AWS KMS is integrated with AWS CloudTrail, a service that delivers log files to an Amazon S3 bucket that you designate. By using CloudTrail, you can monitor and investigate how and when your master keys have been used and by whom.
If you want a managed service for creating and controlling your encryption keys, but you don’t want or need to operate your own HSM, consider using AWS Key Management Service.
HSM: third-party validated hardware security modules under your exclusive control.
CloudHSM (The Calculator): It is designed to perform math inside its secure boundary. You send it data and say "Sign this with Key #101." The key never leaves the hardware; only the result (the signature) comes out.
Secrets Manager (The Vault): It is designed to "give" you the secret so you can use it. You ask for "DB_PASSWORD," and it sends the plaintext string to your application so your app can log in to a database.
Feature
AWS KMS
AWS CloudHSM
Tenancy
Multi-tenant. Shared hardware, but logically isolated keys.
Single-tenant. Dedicated physical hardware just for you.
Management
Fully Managed. AWS handles scaling, patching, and durability.
Self-Managed. You manage users, backups, and clustering.
Integration
Seamless. Works with almost all AWS services (S3, EBS, RDS).
Manual. Requires custom integration via APIs (PKCS#11, JCE).
Key Export
No. Keys generally cannot leave the service.
Yes. You can export keys (wrapped) for use elsewhere.
Compliance
FIPS 140-2/3 Level 3. (High).
FIPS 140-2/3 Level 3. (Highest physical control).
Pricing
Low. $1/month per key + request fees.
High. ~$1.45+ per hour, per HSM instance (~$1,000+/mo).
